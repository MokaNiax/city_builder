# city_builder

> [!NOTE]
> city_builder is a template that allows anyone to start their own 2D city builder with a comprehensive foundation.


_Game engine :_

![Godot](https://img.shields.io/badge/Godot-478CBF?style=for-the-badge&logo=godotengine&logoColor=white)


> [!IMPORTANT]
> W/A/S/D to move around\
> Q/D to turn camera\
> R to rotate a build\
> Escape to leave the game\
> Mouse wheel to zoom and unzoom
